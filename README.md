# 재생에너지 고정가격 입찰제도 해설

RPS 고정가격계약 경쟁입찰(태양광·풍력)의 구조, 평가 기준, 최근 입찰 실적, 2027년 재생에너지 계약시장 전환까지 한 페이지로 정리한 해설 사이트입니다.

- 페이지: `index.html` (의존성 없는 단일 HTML, Google Fonts만 외부 로드)
- 디자인: GriDeX 디자인 베이스 토큰(네이비·라임, Pretendard 폴백)
- 자료 기준: 2026년 10월

## GitHub Pages

공개 주소: https://gridex-khj.github.io/EnergyFixedBidding/

`gh-pages` 브랜치에서 배포됩니다. 페이지를 고친 뒤에는 같은 커밋을 `gh-pages`에도 푸시하십시오.

```
git push origin HEAD:gh-pages
```

## 내용 구성

| 섹션 | 내용 |
|---|---|
| 제도란 | 판매자·구매자·고정 대상(SMP+1REC) |
| 도입 배경 | 사업자·정부 양측의 필요 |
| 가격 구조 | SMP 변동을 REC 정산이 메우는 구조, 상한가·우대가격·가중치 |
| 절차 | 선정 의뢰 → 공고 → 접수 → 평가 → 배분 → 계약, 경쟁률 1.1:1 원칙 |
| 평가 기준 | 태양광(계량 90 + 사업내역서 10), 풍력(사업내역서 50 + 가격 50) |
| 정산금 | 돈의 흐름, 두 계약 방식(A·B) 공식, 공단 공식 예시, 정산금 계산기, SMP 민감도, 정산상한·출력제어·공제 항목 |
| 선정 후 | 계약 2개월, 준공기한, 기자재 변경, 계약 취소 시 3년 참여 제한 |
| 미선정 시 | 탈락 사유, 판로 6가지(현물·자체계약·직접 PPA·전환시장·소규모·신규 계약시장), 상황별 선택표 |
| 현물 폐지 후 | 2029년 말 REC 현물시장 폐지 일정, 사업자 유형별 영향, RE100 판매 시 가중치 손익, 전환 시점 판단 |
| 입찰 실적 | 2023~2026년 태양광·풍력 회차별 결과와 낙찰가 추이 차트 |
| 연혁 | 2012년 RPS 시행부터 2027년 계약시장 시행까지 |
| 2027년 이후 | RPS vs 재생에너지 계약시장 비교, 사업자 선택지 |
| 용어 · 출처 | 핵심 용어 8개, 참고 자료 19건 |

## 갱신

수치는 공개 보도자료와 공고문을 종합한 것입니다. 새 회차가 공고·발표되면 `index.html`의 **입찰 실적** 표와 차트, **히어로** 핵심 수치를 갱신하십시오.
